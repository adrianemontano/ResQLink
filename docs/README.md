# Project Summary

**Project Name**

**ResQLink: A Volunteer-Based Emergency Alert and Dispatch Coordination Support System**

**Purpose**

ResQLink is designed to support the **Notify–Receive–Dispatch** workflow by enabling verified barangay volunteers to submit structured disaster incident reports to a centralized dispatcher dashboard. The system aims to improve incident reporting, situational awareness, and dispatch coordination for the Cebu City Disaster Risk Reduction and Management Office (CCDRRMO).
